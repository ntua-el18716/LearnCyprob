# LearnCyprob

A fact-based, interactive explainer of the Cyprus problem negotiations and of a bizonal, bicommunal federation.

- Spec: [`PLAN.md`](PLAN.md)
- Working rules (for contributors and Claude): [`CLAUDE.md`](CLAUDE.md)

## Getting started

Requires Node 22 (see `.nvmrc`).

```bash
npm ci
npm run dev     # local dev server
npm run build   # astro check + production build
```
